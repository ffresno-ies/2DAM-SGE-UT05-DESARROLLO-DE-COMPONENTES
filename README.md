## 📘 Contenidos del Tema 5

En este repositorio encontrarás los recursos necesarios para crear tu **primer módulo en Odoo**, aprendiendo paso a paso desde la estructura inicial hasta la creación de modelos y vistas avanzadas.

Cada documento desarrolla un aspecto clave del proceso:

## 🧱 ¿Qué aprenderás en este módulo?

* Crear la estructura de un módulo con `odoo scaffold`
* Definir campos y modelos personalizados
* Cargar datos de prueba para desarrollo
* Crear y modificar vistas XML
* Construir relaciones entre modelos (M2M, O2M, M2O)
* Comprender el ciclo de vida de un módulo en Odoo
* Añadir un icono a la aplicación o módulo en Odoo
* Entender las tablas asociadas a los modelos (entidades) por medio del ORM de Odoo

---

## 🛠 Requisitos

* Instalación de Odoo y PostgreSQL (preferiblemente en Docker)
* Entorno de desarrollo configurado
* Módulos personalizados en el directorio `custom-addons/`
